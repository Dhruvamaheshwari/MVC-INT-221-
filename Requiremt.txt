⁡⁢⁢⁣​‌‍‌Controller​⁡
to create the Basic controller -> php artisan make:controller FirstIsController
to create invokable controller -> php artisan make:controller InvokableIsController --invokable
to create resource controller -> php artisan make:controller ResourcesIsController --resource
to create API controller -> php artisan make:controller APIIsController --api


​‌‍‌⁡⁢⁢⁣Middleware⁡​
to create the middleware -> php artisan make:middleware MiddlewareIS
    Stpe 1 : cretate controller with any name
    Stpe 2 : write inside teh method of controller success middleware is created
    Stpe 3 : import controller inside in web.php
    Stpe 4 : give suitable routing to the controller
    Stpe 5 : create new middleware with php artisan make:middleware Mymiddleware
    Stpe 6 : set condition in the created middleware
    Stpe 7 : register for the middleware in app.php in bootstrap folder
    Stpe 8 : add middleware in the routing in web.php
    Stpe 9 : Finally run your url with normal url, then restricted parameter which is age for checking middleware is working or not

to create Globlae middleware -> php artisan make:middleware GlobalIsMiddleware
